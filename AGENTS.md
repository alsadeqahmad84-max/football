# OpenSpec workflows

When a task involves planning or implementing a feature with OpenSpec, use the matching skill under `.agents/skills/openspec-*` and follow the project's `openspec/config.yaml` and current change artifacts. Use `openspec update` to refresh generated skills after changing the OpenSpec profile.

## Gaze release notes

When the user says **“gaze this”** while asking to draft, rewrite, or review Gaze GitHub release notes, use `.agents/skills/gaze-release-notes/SKILL.md`. Also use it for requests to draft Gaze release notes or prepare a Gaze GitHub Release body. Follow its required structure, voice rules, and pre-publish checklist.
